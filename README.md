# ビューティーサロン703 公式サイト

Next.js / TypeScript / App Routerで制作した公式サイトです。HOMEを入口に、サロン紹介、メニュー・料金、ブログ、お知らせ、アクセス、お問い合わせを独立ページに分けています。未確定のメニュー、料金、LINE、SNSは架空情報を作らず、設定待ちの安全な表示にしています。

## 情報の更新場所

`lib/site-config.ts` に店舗情報、LINE・SNS URL、メニュー、ブログ、お知らせをまとめています。

- `lineUrl`：公式LINE URLを設定
- `socialLinks`：公式SNSのみ追加
- `menuItems`：メニュー名、説明、料金、所要時間、画像を追加
- `newsItems` / `blogItems`：CMS連携前の仮データを追加

## 写真の差し替え

現在は正式写真を待つプレースホルダーです。`public/images/` へ画像を入れ、`app/page.tsx` の該当 `PhotoPlaceholder` を Next.js の `Image` に置き換えてください。

| 配置場所 | 推奨サイズ | 推奨比率 | 内容 |
| --- | ---: | ---: | --- |
| ファーストビュー | 1800 × 1200 px以上 | 3:2 横長 | 店内またはサロンの空気感 |
| SALON 店内 | 1600 × 1200 px以上 | 4:3 横長 | 店内全体、自然光、清潔感 |
| SALON メニュー・施術 | 1200 × 1500 px以上 | 4:5 縦長 | 手元やメニュー写真 |
| オーナー写真（将来） | 1200 × 1500 px以上 | 4:5 縦長 | 加藤直美さんの自然な姿 |
| 店舗外観（将来） | 1600 × 1200 px以上 | 4:3 横長 | 来店時に分かりやすい外観 |

画像はWebPまたはAVIFを推奨し、被写体の重要部分が中央に寄りすぎない構図が適しています。

## CMS連携

最初はローカルデータで表示し、microCMS設定後に取得関数だけを差し替える想定です。APIキーは環境変数で管理し、未設定・取得失敗時は空配列を返すことでサイト全体を停止させません。

## 開発

```bash
npm install
npm run dev
```

Vercel向けの静的出力は `npm run build` で `out/` に生成されます。ChatGPT Sites向けの出力は `npm run build:sites` で `dist/client/` に生成されます。
